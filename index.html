In-Class Exercise: Fork, Commit Pull Request (Sep 29, 2026)

We will use GitHub forks and pull requests to create 16 different designs for this page. The HTML stays the same for everyone, but each of you will write your own stylesheet for it. On GitHub, a fork is your own copy of someone else's repository. You can change it however you like without affecting the original. A pull request is how you offer your changes back: it asks the owner of the original repository to review your changes and pull them into their project.

To add your stylesheet, you'll use the following workflow:

  1. Download: go to github.com/severinbunse/fork-commit-pullrequest-Core1, click Code → Download ZIP, unzip it, and open the folder in VS Code.
  2. Fork: on the same page, click Fork to make your own copy of this repository on GitHub.
  3. Style: in the themes folder, open the file with your first name, for example themes/severin.css. It already lists everything on this page you can style, so you can focus on styling. To see your changes, open index.html in your browser, choose your name from the Stylesheet menu at the top of the page, and reload after every change. Change only your own file: no HTML, and no one else's CSS.
  4. Commit: on your fork on GitHub, open your CSS file and click the pencil icon to edit it. Select everything in the editor, paste in your code from VS Code, and click Commit changes.
  5. Pull request: on your fork, click Contribute → Open pull request, then Create pull request. I'll review it and merge it.
